# Savage Wheels for GFOS

The AmiCradle Team's port of Savage Wheels (KenamicK Entertainment's
top-down car-crashing derby) to GFOS: AmigaOS 3.2 with GFOpenUp,
68040/68060 + FPU, on GFOpenUp's SDL 2. It ships as a release archive with
an Installer and as the GFOpenUp part Parts/SavageWheels.

Upstream and its game data are fetched at build time
(package/savagewheels.lock); this repository holds only the Amiga port.
See [AMIGA_PORT.md](AMIGA_PORT.md).
